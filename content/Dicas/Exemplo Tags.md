# Como funcionam as Tags?

As tags são uma forma poderosa de conectar assuntos diferentes, **independente da pasta** em que eles estão.

Por exemplo, esta nota está na pasta **Dicas**, mas ela tem as tags: `#exemplo`, `#quartz` e `#guia`.

## O que acontece?
O Quartz cria automaticamente páginas especiais para cada uma dessas tags:
- [/tags/exemplo](tags/exemplo)
- [/tags/quartz](tags/quartz)
- [/tags/guia](tags/guia)

Se você clicar em qualquer um desses links, verá uma lista de **todas** as notas que usam aquela tag. É excelente para criar "temas transversais" no seu blog!
