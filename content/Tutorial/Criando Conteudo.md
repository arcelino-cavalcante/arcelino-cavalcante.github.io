Este é um guia rápido sobre como adicionar diferentes tipos de mídia e organizar seu conteúdo no **Obsidian** para que ele apareça perfeitamente aqui no site.

## 1. Imagens e Mídia 🖼️

O Obsidian (e o Quartz) facilita muito o uso de imagens.

### Como fazer:
1.  **Copie e Cole**: Simplesmente copie uma imagem da internet ou do seu computador e cole (`Ctrl+V`) na sua nota.
2.  **Arrastar e Soltar**: Arraste a imagem da pasta para dentro da nota.

O código ficará assim:
`![[NomeDaImagem.png]]`

Se quiser ajustar o tamanho, pode usar:
`![[NomeDaImagem.png|300]]` (onde 300 é a largura em pixels).

## 2. Incorporar PDFs 📄

Você pode ler PDFs diretamente no site!

### Como fazer:
Igual às imagens! Basta arrastar o PDF para a nota.
`![[documento.pdf]]`

Isso criará uma visualização embutida do PDF na página.

## 3. Links para Outros Arquivos 🔗

Para criar links entre suas notas (o poder do "Segundo Cérebro"):

*   **Link Interno**: Digite `[[` e comece a escrever o nome da nota.
    *   Exemplo: `[[Sobre]]` vira um link para a página "Sobre".
*   **Link Externo**: Use o padrão Markdown `[Texto](URL)`.
    *   Exemplo: `[Google](https://google.com)`

## 4. Criando Novas Categorias (Pastas) 📂

Você perguntou sobre criar uma pasta "Materiais". O processo é simples, pois o Quartz espelha suas pastas do Obsidian.

1.  **Crie a Pasta**: No menu lateral do Obsidian, clique com o botão direito -> "Nova Pasta" (ex: `Materiais`).
2.  **Crie o Index**: Dentro dessa nova pasta, crie uma nota chamada `index.md`.
    *   Essa nota será a "Página Inicial" daquela categoria.
3.  **Adicione Conteúdo**: Coloque suas notas dentro da pasta.

### Exemplo Prático: Pasta "Materiais"
Se você quer uma área para guardar PDFs de aulas:
1.  Crie a pasta `Materiais`.
2.  Dentro dela, crie `index.md` (Título: "Meus Materiais de Estudo").
3.  Arraste seus PDFs para essa pasta ou crie notas específicas para eles, como `Materiais/Aula 01.md`.
