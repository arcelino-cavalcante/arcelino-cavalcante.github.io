Se você decidiu que quer aprender a programar, 9 a cada 10 desenvolvedores vão te dar o mesmo conselho: *"Comece pela Lógica de Programação"*.

Mas o que isso realmente significa? 

Muitos iniciantes travam tentando decorar elementos de sintaxe do JavaScript, Python ou C++. Mas decorar comandos de uma linguagem é como decorar palavras do dicionário de inglês sem saber formar uma frase. A Lógica de Programação é a **gramática** do código.

Neste artigo, vou desmistificar o que é e como você pode treinar o seu cérebro para pensar como um computador.

---

## A Máquina Não É Inteligente, Ela É Obediente

A primeira coisa que você precisa entender é que o computador é uma máquina extremamente rápida, mas totalmente burra. Ele não sabe o que é "fazer um café". 

Se você pedir para um humano: *"Faz um café pra mim?"*, ele sabe pegar a água, botar no filtro, colocar o pó, etc.

Se você pedir para um computador, ele vai perguntar:
1. Como ando até a cozinha?
2. Em que ângulo abro a torneira?
3. Como pego o pó? Quantos gramas?
4. Qual é o algoritmo para misturar tudo?

A lógica de programação nada mais é do que **a habilidade de quebrar um problema gigante em micro-passos sequenciais incrivelmente óbvios e literais**. Isso é chamado de criação de *Algoritmos*.

---

## Os 3 Pilares Fundamentais

Não importa se você vai criar um site, um aplicativo para Android, ou a inteligência artificial de um drone. A lógica baseia-se em 3 conceitos universais:

### 1. Variáveis (As caixas de armazenamento)
Você precisa guardar informações para a máquina lembrar. 
*Imagine uma caixa de sapatos etiquetada "Idade". Dentro da caixa, você guarda o número 25. Sempre que precisar saber a idade da pessoa, o programa abre essa caixa.*

### 2. Condicionais (As bifurcações do caminho)
A base da inteligência do código é o temido `IF` (Se) e `ELSE` (Senão).
*É a capacidade de tomar decisões. "SE a caixa 'Idade' for maior ou igual a 18, imprima 'Pode entrar na festa'. SENÃO, imprima 'Volte para casa'."*

### 3. Laços de Repetição (Loops)
Computadores são fenomenais em fazer trabalhos repetitivos sem cansar. O `FOR` (Para) e o `WHILE` (Enquanto) representam os *loops*.
*Em vez de escrever 1.000 linhas de código mandando a máquina contar estrelas, você escreve que ENQUANTO o número de estrelas for menor que 1.000, repita o processo de contagem.*

---

## Como Treinar a sua Lógica Diariamente

Você não precisa de um computador para ser um bom programador lógico. Tudo na nossa vida é um algoritmo.

Tente fazer este exercício hoje: **Escreva no papel o algoritmo de tomar banho.** 

Lembre-se de todas as etapas (checar a temperatura, tirar as meias, pegar a toalha, verificar se tem shampoo "Se tiver, use. Senão, pegue o sabonete", etc).

Quando você for para a frente da tela codificar sua primeira aplicação web, você vai perceber que escrever as linhas de código é a parte fácil. Pensar antes em qual sequência o problema deve ser resolvido é onde mora o verdadeiro talento do desenvolvedor.
